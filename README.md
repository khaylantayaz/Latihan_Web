## Keahlian
HTML5:
-Membuat struktur dasar dokumen web (<!DOCTYPE html>).
-Menggunakan tag dasar seperti paragraf (<p>), judul (<h1> - <h6>), gambar (<img>), dan tautan (<a>).
-Membuat daftar (list) dan formulir sederhana (<form>).

CSS3:
-Mengatur warna teks dan latar belakang (background).
-Mengatur jenis dan ukuran tulisan (font-style, font-size).
-Memahami konsep Box Model sederhana (margin, padding, border).
-Merapikan tata letak halaman web menggunakan Flexbox dasar.

## Proyek
Membuat HTML yaitu Sebuah halaman web statis sederhana yang berisi biodata, jadwal pelajaran, dan hobi,serta membuat lagu menggunakan HTML dan CSS.
